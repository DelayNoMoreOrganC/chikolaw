# 行政管理要求摘要（来源：律所共享文件夹）

> 原文：`系统行政管理要求.docx`、`系统问题.xlsx`（表1 案件管理项目、表2 终止委托申请表）

## 一、客户管理

1. **客户库**：支持 Excel 导入历史客户；**利冲通过后方可新建**；冲突可申请豁免（须审批）再立案。
2. **必填**：客户名称；客户类型（个人/企业/金融机构/事业单位/党政机关/社会团体/其他）；客户角色（委托人/当事人/对方当事人/第三人/顾问单位/其他同案人）；角色为委托人时必填案源人、所属部门、所属人；个人必填身份证号（同名须校验身份证）。
3. **权限**：管理员可改删全部；其他员工可新建、关联案件前可删客户、可改信息但不可改客户名称；案源人变更须行政审批；详情可见性按部门主管/承办律师/协办律师控制。
4. **模糊查找**：相似名称提示（如佛山XX公司 vs 佛山市XX公司）；按部门/律师/案件类型筛选。

## 二、案件管理（表1）

| 大类 | 合同号模板 | 案件名称规则 |
|------|------------|--------------|
| 民事 | [年]粤至高民字第XXX号 | 当事人与对方当事人+案由 |
| 刑事 | [年]粤至高刑字第XXX号 | 犯罪嫌疑人+案由 |
| 行政 | [年]粤至高行字第XXX号 | 当事人与对方当事人+案由 |
| 非诉 | [年]粤至高非字第XXX号 | 当事人+案由 |
| 顾问 | [年]粤至高顾字第XXX号 | 当事人+业务类型 |

共性必填：收案日期、委托人/当事人（多选）、案由、主办律师、主办部门、协办律师/助理、协办部门、案情简介、收费方式（单选）、分配比例（合计100%）、备注。

专项：诉讼类 — 审级、受理法院、法院案号、开庭日期；刑事 — 犯罪嫌疑人、代理类型；非诉 — 涉案标的/标的物；顾问 — 合同起止日期；风险收费 — 涉案标的（万元）必填；免费代理 — 须主任审批理由。

## 三、流程

- 立案：表1必填项完成后方可提交审批（自动通过/正常审批/特殊审批/提醒）。
- 盖章审批：案件项下文书上传、编号。
- 终止委托：见表2《案件终止委托申请表》。
- 归档：审批通过后自动生成档案号，行政填写归档日期、立卷人、页数、保管期限、密级。
