🔧 技术实现细节

1. 前端动态验证规则（create.vue）

法院案号验证：
诉讼类案件（CIVIL/COMMERCIAL/ARBITRATION/CRIMINAL/ADMINISTRATIVE）必填
非诉讼类案件（ADVISORY/NPA）不强制要求
开庭日期验证：
诉讼类案件必填
日期不能早于收案日期（通过 disabled-date 实现）
合同日期验证：
顾问类案件（ADVISORY）必填
结束日期必须 >= 开始日期
代理类型验证：
刑事案件（CRIMINAL）必填
选项：PLAINTIFF（原告/被害人）、DEFENDANT（被告）

2. 后端自定义验证器（@PercentageSum）

// 验证器注解定义 @Documented @Constraint(validatedBy = PercentageSumValidator.class) @Target({ElementType.TYPE}) @Retention(RetentionPolicy.RUNTIME) public @interface PercentageSum { String message() default "分配比例总和必须为100%"; ... } // 验证器实现 public class PercentageSumValidator implements ConstraintValidator<PercentageSum, Object> { // 通过反射获取三个字段值 // sourcePersonPercentage + departmentPercentage + firmPercentage = 100% // 允许BigDecimal精度误差 }

3. DTO类增强

优化前：
@Data public class CaseCreateRequest { private LocalDate acceptanceDate; private String sourcePerson; private BigDecimal sourcePersonPercentage; ... }
优化后：
@Data @PercentageSum(message = "案源人、承办部门、 律所提留三者比例之和必须为100%") public class CaseCreateRequest { @NotNull(message = "收案日期不能为空") private LocalDate acceptanceDate; @NotBlank(message = "案源人不能为空") private String sourcePerson; private BigDecimal sourcePersonPercentage; ... }
