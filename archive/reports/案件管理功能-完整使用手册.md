## 📝 新建案件操作指南

### 步骤1：进入新建案件页面

**方法1：通过菜单**
```
登录后 → 点击左侧菜单"案件管理" → 点击"新建案件"按钮
```

**方法2：直接访问**
```
在浏览器地址栏输入：http://localhost:3017/case/create
```

### 步骤2：填写案件基本信息

#### A. 基本信息（必填）

| 字段名称 | 是否必填 | 说明 | 填写示例 |
|---------|---------|------|---------|
| 案件类型 | ✅ 必填 | 下拉选择 | 民事/刑事/行政/非诉/顾问 |
| 案件程序 | ✅ 必填 | 下拉选择 | 一审/二审/再审/执行/其他 |
| 案件名称 | 可选 | 自动生成或手动填写 | 为空时根据当事人生成 |
| 案由 | ✅ 必填 | 下拉选择或输入 | 买卖合同纠纷 |
| 管辖法院 | ✅ 必填 | 搜索选择 | 输入"北京"后选择 |
| 案件等级 | ✅ 必填 | 下拉选择 | 一般/重要/次要 |
| 主办律师 | ✅ 必填 | 下拉选择 | 选择负责律师 |

#### A2. 补充信息（对标行政管理要求）

| 字段名称 | 是否必填 | 适用条件 | 说明 |
|---------|---------|---------|------|
| 收案日期 | ✅ 必填 | 全部案件 | 案件立案日期 |
| 法院案号 | ✅ 必填 | 诉讼类 | 格式：（2025）京0105民初1234号 |
| 开庭日期 | ✅ 必填 | 诉讼类 | 开庭审理日期 |
| 合同开始日期 | ✅ 必填 | 顾问类 | 顾问服务开始日期 |
| 合同结束日期 | ✅ 必填 | 顾问类 | 顾问服务结束日期 |
| 代理类型 | ✅ 必填 | 刑事类 | 原告（被害人）/被告 |
| 案源人 | ✅ 必填 | 全部案件 | **可多选**，选择来源律师 |
| 犯罪嫌疑人 | 可选 | 刑事类 | 嫓名 |
| 涉案标的 | 可选 | 风险代理 | 单位：万元 |

#### A3. 分配情况（重要）

| 字段名称 | 说明 | 验证规则 |
|---------|------|---------|
| 案源人比例(%) | 案源人的分配比例 | 与部门、律所比例之和必须=100% |
| 承办部门比例(%) | 部门的分配比例 | 与案源人、律所比例之和必须=100% |
| 律所提留比例(%) | 律所的分配比例 | 与案源人、部门比例之和必须=100% |

**示例**：
- 案源人比例：30%
- 承办部门比例：40%
- 律所提留比例：30%
- **总和：100%** ✅

### 步骤3：添加当事人

1. 滚动到"当事人信息"部分
2. 点击"添加当事人"按钮
3. 填写当事人信息：
   - 当事人类型：个人/单位
   - 当事人角色：原告/被告/申请人/被申请人/第三人
   - 姓名：必填
   - 是否客户：勾选如果是客户
   - 联系电话：必填
   - 身份证号：个人必填
4. 可添加多个当事人

### 步骤4：填写代理费信息

1. 滚动到"代理费"部分
2. 选择收费方式：
   - 固定收费
   - 风险代理
   - 固定+风险
   - 免费代理
   - 未确定
3. 填写标的额（如适用）
4. 填写代理费金额
5. 填写收费简介和备注

### 步骤5：提交案件

**提交选项**：
1. **保存草稿**：暂存案件信息，稍后继续
2. **确认立案**：正式立案，案件状态变为"审理中"
3. **提交案件**：提交案件进行审批
4. **提交审批**：提交审批流程

## 🎯 功能亮点

### 1. 智能自动生成

#### 案号自动生成
- 格式：[年]粤至高[民/刑/行/非/顾]字第XXX号
- 示例：2026粤至高民字第0001号
- ✅ 无需手动填写

#### 案件名称自动生成
- 规则：当事人 + "Vs" + 对方当事人 + 案由
- 示例：张三 Vs 李四 买卖合同纠纷
- ✅ 为空时自动生成

### 2. 动态表单验证

#### 条件必填
- 诉讼类案件：法院案号、开庭日期必填
- 顾问类案件：合同开始/结束日期必填
- 刑事案件：代理类型必填

#### 日期逻辑验证
- 收案日期：不能选未来日期
- 开庭日期：不能早于收案日期
- 合同结束日期：不能早于开始日期

#### 比例验证
- 案源人比例 + 部门比例 + 律所比例 = 100%
- 实时提示，提交前强制校验

### 3. 多选功能（第4轮新增）

#### 案源人多选
- 点击案源人下拉框
- 可选择多个律师
- 示例：张律师、李律师、王律师

#### 部门多选
- 主办部门：可选择多个部门
- 协办部门：可选择多个部门
- 示例：诉讼一部、诉讼二部、行政部

### 4. 业务类型动态选项

根据案件类型，业务类型下拉选项自动变化：

**民事案件**：
- 婚姻家庭、公司、金融、证券、保险、海事海商、建设工程、劳动、知识产权

**刑事案件**：
- 一般代理、当事人自行委托、法律援助、法定通知辩护、扩大通知辩护、刑事附带民事诉讼

**行政案件**：
- 一般代理/应诉、行政申诉

**非诉案件**：
- 公司、金融、证券、保险、反垄断、建设工程与房地产、劳动、知识产权、税法

**顾问案件**：
- 常年法律顾问、专项法律顾问

## ⚠️ 常见问题

### Q1: 点击"新建案件"后页面空白？
**A**: 前端开发服务器未启动。
```bash
cd D:\ZGAI\frontend
npm run dev
```

### Q2: 提交案件时提示"系统内部错误"？
**A**: 后端服务未启动或数据库连接失败。
```bash
cd D:\ZGAI\backend
mvn spring-boot:run
```

### Q3: 分配比例总是提示不等于100%？
**A**: 三个比例字段必须精确等于100.00%，允许小数点后两位。
- 示例：30.00 + 40.00 + 30.00 = 100.00 ✅
- 错误：30 + 40 + 30 = 100 ❌

### Q4: 案源人多选如何操作？
**A**:
1. 点击"案源人"下拉框
2. 勾选多个律师
3. 点击外部关闭下拉框
4. 显示格式：["张律师", "李律师"]

### Q5: 开庭日期无法选择？
**A**:
1. 确保案件类型为诉讼类（民事、刑事、行政、仲裁）
2. 非诉讼类案件不显示开庭日期字段
