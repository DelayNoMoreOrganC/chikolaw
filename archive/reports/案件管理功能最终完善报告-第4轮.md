## 📋 本次优化核心

### 问题识别
参考文档《系统问题.xlsx》行26明确要求：
> "案源人、案源人分配比例%、承办部门分配比例%、律所提留比例%（**案源人和部门可多选**，案源人或部门多于一个时，相加比例=100%；案源人比例+部门比例+律所比例=100%方能提交立案）"

**之前的实现问题**：
- ❌ `sourcePerson` 是单个字符串，不支持多人
- ❌ `hostDepartment` 是单个字符串，不支持多部门
- ❌ `coDepartments` 是单个字符串，不支持多部门

**本次修复**：
- ✅ 改为支持JSON数组格式
- ✅ 前端使用Element Plus的`multiple`属性支持多选
- ✅ 后端使用`@Lob` + `text`类型存储JSON数组

## 🔧 技术实现

### 后端修改（Case.java）

#### 1. 案源人字段（支持多人）
```java
/**
 * 案源人（支持多人，JSON数组格式存储）
 * 示例：["张律师", "李律师"]
 */
@Lob
@Column(name = "source_person", columnDefinition = "text")
private String sourcePerson;
```

#### 2. 主办部门字段（支持多部门）
```java
/**
 * 主办部门（支持多部门，JSON数组格式存储）
 * 示例：["诉讼一部", "诉讼二部"]
 */
@Lob
@Column(name = "host_department", columnDefinition = "text")
private String hostDepartment;
```

#### 3. 协办部门字段（支持多部门）
```java
/**
 * 协办部门（支持多部门，JSON数组格式存储）
 */
@Lob
@Column(name = "co_departments", columnDefinition = "text")
private String coDepartments;
```
